## 5. 为什么不直接删掉

这份看板是「某一版软件为什么要那样改」的原始记录：卡片的 `note` 里有大量
根因分析、实测数据和验收结论（例如写锁卡死的线程栈、安装包改名前后的实测），
删掉就再也找不回来了。归档后 git 历史、内容与检索能力都还在，只是不再挡在根目录。

## 6. 想继续用看板怎么办

看板是开发工具自己写的文件，不参与构建与测试。若以后还要用它管任务，
让工具在仓库根目录重新生成一个 `.dsh-kanban.json` 即可；
旧的那份留在 `docs/archive/`，不需要合并回来。
