# 会话列表滚动跟随与会话区圆角 · 视觉证据

同一台机器、同一套模拟演示数据、1440×900 浅色主题、Chrome 无头浏览器。两张主图都是「打开一条长会话并滚到底部」这一相同场景、相同视口与相同主题。

| 文件 | 版本 | 场景 |
| --- | --- | --- |
| `before.png` | 基线 `92f9618`（改动前） | 长会话把整页撑高，滚到底部后左侧会话列表被滚出视口（空白），右侧会话区是一整块贴边的方形白板 |
| `after.png` | 本 PR 的功能提交 | 同一页、同一视口、同一滚动位置：会话列表完整留在左侧，消息区在自己的容器内滚动；右侧会话区收成圆角描边卡片 |
| `before-corner-tl.png` / `after-corner-tl.png` | 同上 | 会话区左上角放大对比：直角 → 圆角描边 |
| `after-corner-br.png` | 功能提交 | 会话区右下角放大：圆角与描边收住输入框 |

数据：模拟后端返回 12 条消息（6 轮问答）与 5 条会话（含 1 条置顶）。基线截图是在改动前用真实浏览器抓取，不是把新样式隐藏后补拍。

滚到底部后的关键指标：

| 指标 | before | after |
| --- | --- | --- |
| 文档滚动高度 / 视口高度 | 3416 / 900 | 900 / 900 |
| 页面滚动位置 | 2516 | 0 |
| `.chat-scroll` 自身滚动 | 无（client 3185 = scroll 3185） | 2542（client 643 / scroll 3185） |
| 首条会话条目距视口顶部 | -2366（已滚出视口） | 150（可见） |
| 右侧会话区圆角 / 描边 | 0 / 0 | 14px / 1px |

上述断言已固化为 `frontend/scripts/verify-chat-layout.mjs`；启动 Vite 后运行 `node scripts/verify-chat-layout.mjs` 即可复查。
