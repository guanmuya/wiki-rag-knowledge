## 4. 创建 tag 与上传

### 4.1 tag

用**平台的 tag 能力**在 `0601afd52cd4efb16de9a014427d154324a71f79` 上创建 `v1.0.22`
（不是 `git tag` + `git push`，也不是 `electron-builder --publish always`），随后核对指向：

```
$ git ls-remote --tags origin v1.0.22
0601afd52cd4efb16de9a014427d154324a71f79	refs/tags/v1.0.22

$ gh api repos/guanmuya/wiki-rag-knowledge/git/ref/tags/v1.0.22
ref=refs/tags/v1.0.22
object.sha=0601afd52cd4efb16de9a014427d154324a71f79
object.type=commit
```

指向与 `master` tip 一致，`object.type=commit`，才继续上传。平台 tag 能力只有 `tag` + `target`、
没有说明字段，产出的是**轻量 tag**（与 v1.0.18 / v1.0.19 / v1.0.20 / v1.0.21 相同）；版本要点写在 Release 正文里。
建 tag 后 `gh release view` 还能看到 `targetCommitish=master`。
