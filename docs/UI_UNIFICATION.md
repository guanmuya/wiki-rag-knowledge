# 前端整体视觉统一 · 方向说明

> 对应需求：「帮我将前端的 UI 整体统一下吧，然后统一的版本最好是你觉得设计感好的那边靠」。
> 本文只回答三件事：识别出了哪两套视觉语言、以哪套为统一基准、为什么。

## 一、识别出的两套视觉语言

先说清一个事实口径：仓库里**没有两套主题**。没有深色模式，没有 `prefers-color-scheme`，
没有 `data-theme`，`:root` 只有一份令牌表（`styles/01-tokens-base.css`）。12 个页面
共用同一个设计系统。差异不在「主题」，而在于**同一套系统长期被两种施工习惯同时使用**——
这确实构成了两套肉眼可辨的视觉语言。

### A 套：令牌驱动的「点阵画布 + 圆角浮层卡片」（较新、较克制）

- 白底 + 22px 点阵画布（`--canvas-bg`），内容是一张张白色圆角卡片：14px 圆角、1px 描边、
  `--shadow-xs`。靠浮起层次分区，而不是靠硬分割线。
- 颜色一律走 `--c-*` 令牌，状态色克制（蓝 / 青 / 琥珀 / 红各一档）。
- 分段控件、卡片化列表项、大号等宽数字指标卡、示例问题 chip、Hero 图标块。
- 由近几轮改动逐步建立：点阵画布（历史截图 `34`/`35`）、会话区圆角卡片
  （`chat-scroll-rounded`）、会话列表卡片化、管理员用量看板（#27）、
  Agent 思考/回答分区（#32，其注释明确写着「复用 07-chat.css 的 .thinking-card，
  与智能问答页同一套语言」），以及去掉彩色药丸标签的几轮收敛（#31–33）。
- 代表页面：知识库列表、检索调试、管理员用量、智能问答（圆角改造后）、Agent 空态卡片。

### B 套：贴边直角「白板」+ 硬编码补丁色（较旧、偏平的后台模板感）

- 内容贴着窗口与侧栏边缘铺满，方形直角，靠 1px 硬分割线分区，侧栏另铺一层灰底。
- **最明显的一处**：`styles/07-chat.css` 用 `.chat-shell:not(.agent-shell)` 只给
  「智能问答」的圆角浮层卡片，把「个人 Agent」明确排除在外。两个整屏页因此一个是浮层卡片、
  一个是贴边白板——这正是「两边」在界面上最容易看到的分歧。
- 分片 02–11 散落大量硬编码十六进制色值：淡蓝 / 淡黄提示条、好几种几乎一样的
  「差一点白」悬停灰、深色代码块，以及登录页自带的一整套藏青 / 浅蓝。数值彼此略有偏差。
- 同一组件被实现多遍且规格不一：`.view-switch` 与 `.usage-segment` 两套分段控件，
  `.card`（14px 圆角、白底标题）与 `.panel`（10px 圆角、灰底标题）两种卡片，
  `.stat-cell` 与 `.usage-metric` 两套数字，以及五六种内边距 / 圆角 / 图标尺寸各异的提示条。
- 代表页面：个人 Agent 整屏页、模型分组、Wiki 侧栏面板、登录页，以及各分片末尾累积的补丁规则。

> 严格说，差异不足以构成两套**完整主题**，也不是五五开的两派页面；更准确的说法是
> 「一套设计系统 + 一层逐页累积的补丁习惯」。所以按需求给出的兜底口径处理：
> 不另造第三套规范，收敛到统一令牌与统一组件口径。

## 二、以哪套为统一基准

**以 A 套为全站基准，把 B 套提升上来，而不是把 A 套削平去迁就 B 套。**

具体是把「智能问答」已有的圆角浮层卡片推广到「个人 Agent」，并把其余页面的色值、
圆角、间距、卡片与表格、页头工具条统一到 A 套口径；登录页右栏也改成点阵画布，
让白色登录卡和其余内容页的卡片落在同一种底上。

## 三、理由

1. **它是现有改动的方向。** 近几轮都在往这套收敛，Agent 思考区的注释甚至明确写着
   「与智能问答页同一套语言」。顺着它走改动最小，也不会和刚做完的改动互相打架。
2. **更克制、更一致。** 一套调色板、一档圆角、一档阴影；用浮起层次代替硬分割线，
   去掉灰底标题条和多余彩色标签后，信息层级反而更清楚。这正是需求里「设计感好」的那一侧。
3. **可维护。** 色值集中到 `:root`，改主题只改一处；此前同一处淡蓝有五种近似写法，
   任何一次调整都会漏掉几处。
4. **符合任务授权。** 需求说「最好是你觉得设计感好的那边靠」，并明确要求
   「不是把各页面削到最朴素的最大公约数」；判断哪一套更好的权限已交给前端成员。
5. **风险可控。** 全部改动可以落在 CSS，不需要改组件结构、接口调用或路由。

## 四、收敛清单（只改 CSS）

| 维度 | 动作 |
| --- | --- |
| 令牌 | `01-tokens-base.css` 补一层语义令牌（交互中性色、info/warn/danger 的底 / 边 / 字、深色代码块、品牌页色、纯白反色、图表序列色），把各分片与 `UsagePage.css` 的硬编码色值全部替换；除 `:root` 定义外不再出现十六进制色值 |
| 圆角 / 间距 | 新增 `--radius-card`、`--space-card`、`--space-card-head`、`--gap-grid`、`--gap-stack`；卡片、面板、表格、弹窗、登录卡、知识库卡片统一到这一档 |
| 组件口径 | 分段控件合并成一套规则（`.view-switch` / `.usage-segment`）；`.panel` 与 `.card` 统一；表格与模型分组统一圆角；提示条收成「页级 / 行内」两档；深色代码块、徽标、占位色共用令牌 |
| 整屏页与卡片页 | 移除 `:not(.agent-shell)` 例外：两个整屏页都落在点阵画布上、会话区都是圆角浮层卡片；侧栏改为与应用侧栏一致的纯白贴边导轨 |
| 页头工具条 | `.page-head` 与用量页 `.usage-page` 共用 `--gap-stack`，页头操作区间距统一 |
| 登录页 | 右栏改点阵画布，白色登录卡浮在同上底上，颜色全部走令牌 |

## 五、边界

- 只改 `frontend/src/styles/*.css` 与 `frontend/src/pages/UsagePage.css`。
  `frontend/src/styles.css` 的 `@import` 顺序未改、未追加规则，分片未重排或单独引入。
- 未改 `frontend/src/**` 的业务逻辑、接口调用、路由与信息架构；未改 `backend/**`。
- 刻意保留：聊天气泡的方向性圆角、SVG 内嵌色、`rgba()` 遮罩与半透明悬停、
  滚动条尺寸——它们不是「两套视觉语言」的分歧点。
- 布局约束延续既有门禁：整屏页仍不撑出页面滚动条，`.chat-main` 保持圆角与描边，
  输入框保持贴底（`frontend/scripts/verify-chat-layout.mjs`、
  `verify-chat-composer-dock.mjs` 的断言口径）。
